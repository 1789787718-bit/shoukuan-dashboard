# 天宏平台车辆收款可视化 Web 系统

针对 `2026年北斗平台服务车辆收款明细表5月.xlsx` 中的第 3 张表——**「天宏平台」**（包含 10,191 条车辆收款数据、29 列明细字段）构建的现代化响应式 Web 数据可视化与分析看板系统。

---

## 🌟 核心功能特性

1. **核心 KPI 全景指标**：
   - 服务车辆总数（10,135 辆）、覆盖客户（3,675 家）
   - 总应收款项（¥3,492,023.14）、总实收金额（¥1,923,675.94）、总欠款金额（¥1,672,076.10）
   - 综合回款达成率（55.09%）
   - 逾期与即将到期车辆实时监控预警（已到期 2,121 辆、30天内到期 463 辆）

2. **四大分析与交互看板**：
   - **📊 业务全景看板**：服务费、第三方收款、设备款、售后款、其他收款 5 大业务板块的收支对比、实收贡献环形图与业务大类分布。
   - **👥 负责人业绩看板**：各业务负责人（封柏、吴锡飞、全柏、郭爱南等）负责车辆数、收款额、欠款额横向柱状图与综合考核排行榜，支持一键下钻查看该负责人名下所有车辆。
   - **⚠️ 欠款与风险监控**：Top 20 欠款大客户排行榜、服务期到期年份账龄分布与重点关注企业清单。
   - **🔍 车辆明细多维检索与档案**：支持车牌/客户名称/备注/设备型号实时模糊检索、多维度组合筛选、各列升降序排列、分页与 **单车全业务档案详情抽屉（Drawer）**。

3. **双模式主题与一键导出**：
   - 支持科技深色模式（Dark Mode）与商务浅色模式（Light Mode）一键切换。
   - 支持根据当前筛选条件一键导出清洗后的 UTF-8 BOM CSV / Excel 文件。
   - 支持「重新同步 Excel」按钮动态更新数据。

## 🚀 启动与使用说明

### 方式一：双击一键启动（推荐）
直接双击运行目录下的：
```bat
start_dashboard.bat
```
系统将自动启动服务并在系统默认浏览器中打开 `http://localhost:8080`。

### 方式二：命令行启动
打开命令行终端，进入项目目录执行：
```bash
cd D:\shoukuan\dashboard
python app.py
```
然后在浏览器中访问：`http://localhost:8080`
