双击项目根目录下的 `start_dashboard.bat`，脚本将自动启动后台服务并自动在默认浏览器中打开系统。

## 📊 系统核心功能板块

### 1. 📊 业务全景看板
- **6 大核心 KPI 指标卡**：服务车辆总数（10,191 辆）、覆盖组织数（1,947 家）、总应收额、总实收额、总欠款额、综合回款达成率与到期预警。
- **五大收费板块对比**：平台服务费、第三方收款、设备款、售后维护款、其他款项的收支柱状图分析。
- **各板块实收贡献环形图** 与 **业务大类规模趋势折柱图**。

### 2. 👥 业务负责人业绩看板
- **业绩与欠款对比柱状图**：支持查看各业务负责人（封柏、吴锡飞、刘美东、庞妃强等）的管辖车辆数、应收总额、实收金额与回款达成率。
- **考核排行榜**：按实收贡献与清欠成效排名，支持一键点击「查看名下车辆」下钻筛选。

### 3. ⚠️ 欠款风险与大客户监控
- **Top 20 欠款大客户排行榜**：直观展示欠费最高的重点组织与欠费金额，点击柱条可直接穿透检索该组织所有欠费车辆。
- **服务期到期年份账龄分布**：提前预测未来到期续费负荷与过期风险。

### 4. 🔍 车辆明细多维检索与档案抽屉 (Drawer)
- **多条件组合秒级检索**：支持按车牌、客户名、备注、设备型号模糊检索，支持按负责人、业务大类、收款状态（已结清/部分收款/未交款）、到期状态组合过滤。
- **单车全业务档案详情抽屉**：点击任意车辆可滑出档案详情，展示该车平台服务费、第三方费、设备款、售后维护款明细、安装日期、到期日与备注，并提供「开具此车单据」一键联动。

## 🧾 财务单据开具与打印中心 (Voucher Print Center)

### 1. 支持 7 套企业标准财务单据 (1:1 还原)
| 序号 | 单据类型 | 单号前缀 | 核心要素与场景 |
| :---: | :--- | :---: | :--- |
| 1 | **销售出货单** | `XK` | 购货单位、送货地址、多行货品明细（车载终端/物联网卡）、车牌摘要、客户/仓管/业务员/开单人签名 |
| 2 | **销售收款单** | `XS` | 客户单位、收款账户（库存现金/天宏工行）、6列核销表（引用单号/单据日期/总金额/已收/未收/本次收款）、摘要与收款公章落款 |
| 3 | **采购付款单** | `CF` | 供应商、工行账户、应付/实付金额、引用入库单核销明细表、付款单位公章栏 |
| 4 | **采购收货单** | `CS` | 进货仓（湛江总仓）、物料规格、税率税额、双边纳税开户信息 |
| 5 | **采购退货单** | `CT` | 冲抵往来退货、物料退还明细、供应商签名 |
| 6 | **销售退货单** | `XT` | 退货客户单位、拆机备注（如 `粤GD96926（拆机）`）、整单折扣 |
| 7 | **销售退款单** | `XF` | 客户退款单位、冲抵往来账户、引用原出货单退费明细与客户确认签名 |

### 2. 单据排版与打印核心技术特性
- **固定 32px 标准行高**：强制锁定明细行高度，消除浏览器默认压缩变形。
- **固定补齐 7 行标准格**：无论录入数据量多少，物理单据高度始终恒定，完美匹配针式打印机二等分联单与 A4 纸张比例。
- **大写金额自动转换**：输入小写数字（如 `¥23,000.00`）自动转换为标准财务大写（`贰万叁仟元整`）。
- **一键导入车辆档案**：在单据中心搜索车牌或客户名称，秒级自动填充单据所有字段。
- **专业 `@media print` 打印**：点击「立即打印单据 / 另存为 PDF」自动隐藏所有网页按钮与菜单，纯净输出标准单据。
